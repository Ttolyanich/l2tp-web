# L2TP Web Hub 🚀

**L2TP Web Hub** — современная легковесная веб-панель управления сервером **L2TP/IPsec (Libreswan + xl2tpd + PPP)**, упакованная в единый Docker-контейнер. Спроектирована специально для централизованного выпуска и администрирования учетных записей удаленных устройств (включая парк **Synology NAS**, роутеры MikroTik и рабочие станции) с жесткой привязкой статических IP-адресов под опрос **Zabbix / SNMP**.

Архитектура проекта, схема авторизации и интерфейс полностью повторяют концепцию и стандарты [openvpn-web](https://github.com/Ttolyanich/openvpn-web) и [centralized-auth](https://github.com/Ttolyanich/centralized-auth).

---

## 🌟 Основные возможности

* **All-in-One Docker контейнер**: Libreswan (IPsec IKEv1/NAT-T), xl2tpd, pppd, фаервол iptables и веб-панель работают в едином оптимизированном окружении.
* **Два режима авторизации администраторов (AUTH_MODE) — скопировано с OpenVPN Web**:
  1. `central` (по умолчанию): Авторизация через центральный сервер **centralized-auth (SSO / CA)** с ролевым доступом (`admin`, `operator`, `viewer`) и поддержкой групп (`ADMIN_GROUP`). Вся аутентификация домена/пользователей делегируется CA.
  2. `standalone`: Автономный запуск с локальной учетной записью администратора (`STANDALONE_ADMIN_USER` / `STANDALONE_ADMIN_PASSWORD`).
* **Управление клиентами и учетными записями в Web UI**:
  - Создание клиентов в один клик с автогенерацией надежного пароля.
  - Автоматическое выделение следующего свободного статического IP из пула (`10.18.15.1 – 10.18.15.254`).
  - Мгновенная синхронизация с `/etc/ppp/chap-secrets`.
  - Возможность временного отключения (Disable) и принудительного сброса зависших туннелей.
* **Готовая памятка для инженеров (Synology DSM)**:
  - Всплывающая карточка с параметрами (Сервер, PSK, Логин, Пароль, IP).
  - Пошаговая инструкция с напоминанием снять галочку *«Использовать шлюз удаленной сети»*.
  - Кнопка *«Скопировать всё текстом»* для быстрой отправки в тикет / чат.
* **Live Мониторинг подключений**:
  - Отображение подключенных клиентов в реальном времени (зеленый пульсирующий индикатор).
  - Учет входящего/исходящего трафика (RX/TX байты) с физических интерфейсов `ppp*`.
* **Встроенный редактор конфигурационных файлов**:
  - Редактирование `ipsec.conf`, `l2tp.secrets` (общий PSK), `xl2tpd.conf`, `options.xl2tpd`, `iptables_rules` прямо в веб-интерфейсе.
  - Автоматическое создание резервных копий (`.bak.<timestamp>`) перед каждым сохранением.
  - Кнопка перезапуска служб IPsec и L2TP прямо из админки.
* **Журнал аудита**: Фиксация всех действий администраторов с IP-адресами и временными метками.
* **Быстрая миграция**: Встроенная утилита импорта существующих 100+ учетных записей со старого сервера без прерывания их работы.

## 📐 Сетевая архитектура и схема работы Zabbix

```
+-------------------+           +-----------------------------------------------+           +--------------------+
|   Zabbix Server   |           |             L2TP Web Hub (Docker)             |           |    Synology NAS    |
|    10.18.8.90     |           |        Внешний IP: 10.18.9.190                |           |    (Филиал/Офис)   |
+---------+---------+           |        Шлюз PPP:   10.18.12.1                 |           +---------+----------+
          |                     +-----------------------+-----------------------+                     |
          | OpenVPN / Корп.сеть                         |                                             | L2TP/IPSec
          | (10.18.8.0/22)                              |                                             | (UDP 500,4500,1701)
          +-------------------------------------------->+ (tun0)                                      |
                                                        |                                             |
                                                        | SNAT (MASQUERADE в 10.18.12.1)              |
                                                        +============================================>+
                                                                  Туннель pppX: 10.18.15.X
                                                                  (SNMP опрос и ловушки)
```

1. Удаленный **Synology NAS** устанавливает защищенный туннель L2TP/IPsec к серверу.
2. Проходит авторизацию **MS-CHAP v2** по логину и паролю из базы `chap-secrets`.
3. Сервер назначает клиенту персональный статический IP (например, `10.18.15.4`).
4. **Zabbix** опрашивает этот IP по SNMP.
5. Правило NAT сервера маскирует входящие запросы от Zabbix в адрес `10.18.12.1`, поэтому Synology отвечает прямо в туннель без необходимости прописывать статические маршруты на самом NAS.

## 🚀 Быстрый старт (Docker Compose)

### 1. Клонирование репозитория
```bash
git clone https://github.com/Ttolyanich/l2tp-web.git
cd l2tp-web
```

### 2. Настройка переменных окружения
Скопируйте шаблон `.env.example` в `.env`:
```bash
cp .env.example .env
nano .env
```

Пример `.env`:
```env
BIND_HOST=0.0.0.0
BIND_PORT=5000
NODE_NAME=L2TP-Gateway-1
PUBLIC_IP=10.18.9.190
L2TP_IPSEC_PSK=L2tP(L2tB)Gbylf2019!

# Режим авторизации (как в openvpn-web):
AUTH_MODE=central
CENTRAL_AUTH_URL=http://host.docker.internal:5001
NODE_API_TOKEN=default-token-change-me-please
ADMIN_USERS=admin,operator_lead
ADMIN_GROUP=VPN_Admins

# Для автономного запуска:
# AUTH_MODE=standalone
# STANDALONE_ADMIN_USER=admin
# STANDALONE_ADMIN_PASSWORD=admin123
```

### 3. Запуск контейнера
```bash
docker compose up -d --build
```

Веб-панель будет доступна по адресу: **`http://<IP_СЕРВЕРА>:5000`**

## 🔐 Авторизация администраторов (AUTH_MODE)

### 1. Централизованный режим (`AUTH_MODE=central`) — Основной
Авторизация делегируется центральному сервису [centralized-auth](https://github.com/Ttolyanich/centralized-auth) (Single Sign-On / CA):
```env
AUTH_MODE=central
CENTRAL_AUTH_URL=https://auth.company.local:5001
NODE_API_TOKEN=your-secret-node-token
VERIFY_SSL=false
ADMIN_USERS=admin,a.ivanov
ADMIN_GROUP=VPN_Admins
```

### 2. Автономный режим (`AUTH_MODE=standalone`)
Подходит для изолированных серверов с локальной учетной записью:
```env
AUTH_MODE=standalone
STANDALONE_ADMIN_USER=admin
STANDALONE_ADMIN_PASSWORD=admin123
```

## 🛠️ Миграция со старого сервера L2TP

Если у вас уже есть работающий сервер L2TP (например, `10.18.9.190`), вы можете импортировать все учетные записи одной командой:

### Через CLI утилиту (по SSH):
```bash
python import_from_server.py --ssh a.ivanov@10.18.9.190 --db data/node.db
```

### Или через Веб-интерфейс:
1. Войдите в панель управления.
2. Нажмите кнопку **«Импорт chap-secrets»**.
3. Вставьте содержимое `/etc/ppp/chap-secrets` со старого сервера.
4. Нажмите **«Выполнить импорт»**. Все клиенты сразу отобразятся в таблице с сохраненными комментариями и IP-адресами.

## 📋 Инструкция по настройке Synology DSM

1. В Synology DSM откройте: **Панель управления &rarr; Сеть &rarr; Сетевой интерфейс**.
2. Нажмите **Создать &rarr; Создать профиль VPN &rarr; Выберите L2TP/IPSec**.
3. Заполните поля:
   - **Имя профиля**: `VPN-Zabbix`
   - **Адрес сервера**: Внешний IP или домен сервера
   - **Имя пользователя**: Логин из панели
   - **Пароль**: Пароль из панели
   - **Общий ключ (Pre-shared key)**: Значение PSK из `l2tp.secrets`
4. В **Дополнительных параметрах**:
   - ⚠️ **Обязательно снимите флажок** *«Использовать шлюз удаленной сети»* (чтобы интернет офиса не маршрутизировался через сервер).
   - Аутентификация: **MS-CHAP v2**.
5. Нажмите **Применить** и **Подключить**.

## 📁 Структура проекта

```
l2tp-web/
├── app.py                     # Основной бэкенд Flask, RBAC, API и роутинг
├── l2tp_manager.py            # Драйвер управления Libreswan, xl2tpd, pppd, IP-пулом
├── import_from_server.py      # Утилита миграции существующих учеток
├── Dockerfile                 # Мультисервисный Dockerfile (Python + Libreswan + xl2tpd)
├── docker-compose.yml         # Compose-манифест с host-networking
├── entrypoint.sh              # Инициализация ядра, sysctl, NSS и iptables
├── supervisord.conf           # Менеджер процессов (Pluto, xl2tpd, Gunicorn)
├── default_configs/           # Эталонные конфиги для первого запуска
│   ├── ipsec.conf
│   ├── l2tp.secrets
│   ├── xl2tpd.conf
│   ├── options.xl2tpd
│   └── iptables_rules
├── static/                    # CSS, палитры оформления и JS SPA
├── templates/                 # Шаблоны Jinja2 (dashboard, login, navbar)
└── requirements.txt           # Зависимости Python (Flask, requests, gunicorn, etc.)
```
